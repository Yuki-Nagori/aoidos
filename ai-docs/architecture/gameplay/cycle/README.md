# 周目生命周期

周目是带有冻结输入、独立预算与历史分支的故事实例。新周目必须经过初始化后才可游玩；运行期间任务是引导投影；只有可信终局事实能触发最终结局。

| 阶段       | 文档                         | 权威边界                                                      |
| ---------- | ---------------------------- | ------------------------------------------------------------- |
| 开局与冻结 | [初始化](initialization.md)  | 人物档案、最终目标、任务初始态、规则和请求账务绑定 run 并冻结 |
| 游玩中     | [任务](tasks.md)             | 主线 / 连续任务引导玩家；完成状态不直接写世界事实或结束周目   |
| 终局       | [结局与落幕](ending-flow.md) | engine 求值、冻结标签和规范摘要；AI 只能提供非权威叙事        |

周目状态恢复和持久化由[存储架构](../../data/storage.md)与[记录引擎](../../data/record-engine.md)共同支撑；任务、记忆刻痕和结局解析不得互相持有生命周期权威。
