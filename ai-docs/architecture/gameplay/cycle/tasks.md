# 周目任务投影

任务栏把开局生成的最终目标与游玩中的局部推进呈现给玩家。它是引导，不是第二套世界状态系统，也不是结束周目的裁决器。

## 任务类型

- **主线最终目标**：每个新周目初始化时生成且唯一，始终置顶并强调。首个引导者在开局交代它；目标文本和完成条件绑定初始化快照。
- **普通任务**：帮助玩家处理当前局部目标，可以来自开局快照或已提交的剧情里程碑。
- **连续任务**：由引擎识别的显式前后依赖串联若干阶段；只展示当前可行动阶段，保持其所属任务链稳定可追溯。

任务 ID 与顺序由 engine 生成。AI 输出只能提供受限候选内容；验证拒绝未知字段、无效依赖、重复 ID、过长文本和对不存在角色 / 事实的隐式引用。未提交、失败、unknown、被回退或重复处理的生成结果不得改变当前任务栏。

## 状态与历史分支

任务状态是当前有效历史分支上的可重建投影。完成项显示划线并移入折叠区；保留记录以支持分支回退与审计。未满足条件的目标保持活动态，不因模型一段叙述宣称“完成”就自动变更。若任务依赖的状态字段缺失或未提交，engine 保持未知状态，不静默当作 false 或 true。

任务完成不等于世界事实、角色获知、结局条件满足或记忆证据。只有对应权威事件经 engine 校验并 applied 后，其他域才可以消费它。

## 展示权限

玩家可见任务只含经公开策略筛选的目标和说明；隐藏真值、秘密标签、角色未公开动机和未授权的未来任务不进入 task DTO。完成历史默认折叠，不能把折叠等同删除。

数据结构、记录类型和恢复契约由 [056](../../../task/056-ending-flow-impl.md) 定稿；周目账务与可删除性由[周目存储架构](../../data/storage.md)负责。
