# 界面国际化与本地化

更新 / 官方资料核验日期：2026-10-06。[028](../task/028-i18n-design.md) 设计定稿，实施由 [034](../task/034-i18n-impl.md) 承接；当前没有翻译运行时或语言命令。界面布局归 [UI shell](ui-shell.md)，首窗构建与 CSP 归[主题架构](theming.md)，费用语义归 [027](../task/027-llm-cost-control-design.md)。

## 语言与内容边界

首版支持 `zh-Hans` 与 `en`。Rust 使用 [sys-locale](https://docs.rs/sys-locale/latest/sys_locale/)读取系统语言并规范化 BCP 47 标签：任何 zh 区域 / 字体变体（包括 zh-TW / zh-HK / zh-Hant）映射 zh-Hans；en 及其区域映射 en；其他、空值和检测失败回退 en。繁体系统显示简体，不能宣称已提供繁体翻译。用户选择优先；system 模式在启动或显式选择 system 时重新检测，不持续监听系统设置。普通浏览器开发确定性使用 en，不从 navigator.language 或 localStorage 建第二份偏好。

界面语言只改变应用文案、辅助技术文案与显示格式，不改变实体 ID、枚举、错误码、骰式、玩家输入、既有记录和日志。剧本元数据可声明有效 BCP 47 `lang`，生成内容按已冻结的剧本 / 请求语言标注；未知语言省略标注，玩家原文不能机械套用剧本语言。界面切换不修改生成语言或重译记录。多语言剧本的内容文件及选择协议由剧本格式另行设计，应用翻译表不承载剧本正文。

## 前端与单一资源源

采用 vue-i18n v11 Composition 模式、`@intlify/unplugin-vue-i18n` 构建期预编译与生产 runtime-only；所有消息为随应用发布的可信资源，禁止运行期编译玩家 / 剧本字符串。保持严格 CSP，不加入 unsafe-eval。v11 默认 JIT / AST 与编译器移除设置需在锁定版本下检查实际产物，不能把“runtime-only”名称当作无编译器证据。[官方优化说明](https://vue-i18n.intlify.dev/guide/advanced/optimization)

拟新增根 `locales/zh-Hans.json`、`locales/en.json`，使用嵌套命名空间 `common / settings / errors / budget / memory / native`。中文文件定义 MessageSchema；英文必须同键、同占位参数与合法复数结构，不只检查键数量。静态引用强类型；动态错误码用显式类型化映射，不能任意拼接 key。使用文本插值或组件插值，不用 v-html 解释译文；用户参数按文本显示。数字、金额和日期由 utils 的薄 Intl 包装格式化，不建立另一套 numberFormats。

两份资源全部预加载，切换不依赖异步网络。发布前缺键 / 无效消息 / 参数不一致直接失败；运行时异常采用 en 回退，再显示稳定通用文案与诊断码，不泄露插值参数。开发告警包含键名，不包含玩家原文。原生键也参与同键检查，不因前端未引用判为废键。

使用 `@intlify/eslint-plugin-vue-i18n` 检查缺键、废键及裸文案；ESLint 10 flat config 兼容性须在 034 核验。若插件暂不兼容，不降级工程门禁：使用构建期资源互校和明确的文案扫描脚本覆盖同等验收，再记录替代原因。ID、日志、测试夹具等豁免必须有明确范围，不能全目录忽略。[官方规则目录](https://eslint-plugin-vue-i18n.intlify.dev/rules/)

## 偏好、IPC 与切换

Rust / SQLite 唯一持久真相源，LocalePreference 为 `{ version: 1, locale: "system" | "zh-Hans" | "en" }`，独立单项配置；不替换 ThemePreference 或 UiPreferences。缺项为 system，坏版本 / 枚举按 store.corrupt 处理，不覆盖坏记录。单项写入原子化，迁移 / IO 错误沿用 store.* / app.not-ready。

设计命令 `locale_get_preference {}` 与 `locale_set_preference { preference }` 均返回 `{ preference, resolvedLocale, nativeStatus }`；resolvedLocale 只能 zh-Hans / en；nativeStatus 为 applied / pending。非法版本 / 枚举为 app.bad-request。Rust 类型定型时同 commit 声明 TS 同型，invoke 仅透传；命令名与错误载荷统一登记[通信契约](ipc-contract.md)。

每应用最多一笔语言写入在飞，后续意图合并为最新值；先确认持久保存，再切 vue-i18n、html lang 与原生文案。旧请求 / 旧视图响应不能覆盖最新意图。保存失败保留上次确认语言；结果不确定主动 get 核验，不重复写来猜测。Rust 原生更新失败不伪装为偏好未保存：返回 pending，显示简短提示；下一次主动读取 / 重试或启动按最新持久值重建。不增加持续轮询、重载页面或改变在飞剧情。

## 首帧初始化与原生界面

034 复用 026 受控 main 构建入口，同一个 initialization_script 注入独立版本的 ThemeBootstrap 与 LocaleBootstrap。LocaleBootstrap 为 `{ version: 1, locale: "zh-Hans" | "en", fallbackReason? }`；fallbackReason 仅 storageUnavailable / invalidPreference。枚举序列化进入受信任脚本，禁止拼接系统 locale 原始字符串。HTML head 在根节点创建后、CSS / module 之前应用 lang，Vue 首次挂载直接使用相同 locale；不等待 mounted invoke 修正文案。CSP、主 frame / 精确 dev origin、显式重载重新读偏好均沿用 026，不二次创建窗口。

读取失败采用 en 临时降级并明确原因，不回写偏好；恢复结果仅在当前视图代次生效。初始化脚本只提供展示 bootstrap，不提供费用默认、密钥或业务状态。两份翻译已打包；首帧、读屏与 html lang 必须一致，设置控件不能把降级值标成已保存偏好。

原生范围含应用菜单、托盘、应用提供的对话框标题 / 内容 / 按钮与窗口标题。Rust 用 build.rs 从相同 JSON 提取 `native.*`，生成嵌入常量表；不另装一套翻译框架、不运行时读文件。原生消息只支持构建时校验过的具名文本占位，复杂复数交前端；构建器与前端对相同占位有共享夹具。菜单动作 ID / 快捷键不随文案变化，切换后按最新 locale 更新 / 重建，不重启应用；已打开的系统对话框可沿用创建时语言，后续新对话框使用新语言。

Tauri 预定义菜单支持自定义 text；隐藏 / 退出等应用可命名标签使用 native.*，不能笼统称为随系统语言。操作系统管理的服务子菜单内容、文件选择器系统按钮等按系统语言，应用只控制其 API 允许设置的文案。[Tauri 菜单 API](https://v2.tauri.app/reference/javascript/api/namespacemenu/)

## 格式化、金额与错误

语言、币种、时区分别传入。显示时间使用显式 IANA 时区；业务月边界在 Rust 计算，Intl 不计算额度周期。非法日期 / 时区显示可诊断占位，不能悄悄改用浏览器本地时区。数字格式化不影响排序、比较或机器序列化。

金额 IPC 为十进制字符串 + CNY / USD；Rust 定点金额与 rust_decimal 转换，禁止 f64。前端不先 Number(amount)：在纯 utils 用字符串 / BigInt 精确舍入到显示位，再用 [Intl.NumberFormat.formatToParts](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/NumberFormat/formatToParts) 的 BigInt 整数分组与货币模板组装小数。CNY / USD 主视图 2 位，请求计价详情最多 9 位；显示舍入 HALF_UP（正负对称），账本精度独立。大额、负额、负零、极小值和不同地区符号位置配黄金测试；若锁定 WebView 支持直接精确格式化十进制字符串，可作为经过实测的替代，不能依赖旧引擎隐式 Number 转换。

首次建预算按 resolvedLocale 冻结明确币种：zh-Hans 为 CNY，其余 USD；后续只能通过费用设置显式改，语言变化不重算已用 / 上限。系统语言、预算币种、预算时区各自持久化，不隐式联动。

错误按 code + 已登记、受约束 detail 映射文案；每个 switch 有 default。未知码显示通用错误 + 码名；CmdError.message 是脱敏兜底 / 可展开诊断，不作为主文案或稳定协议，不把任意 detail 展开进页面。切换语言重新渲染码映射，不残留旧语言终态提示。实体 / 模型名称为原始身份文本，翻译只包裹上下文。

## 实施与验证

034 负责翻译资源、偏好、bootstrap、原生界面、薄格式化与错误映射底座，以及当前示例的接入。025 消费这些能力交付完整游戏 UI，031 接记忆高级设置，027 后续费用实施消费精确金额与 locale。设计不安装依赖，jiff 属费用月边界实现，rust_decimal 可与费用共享工作区版本。

验收覆盖双语言资源 / 参数与 locale 集合互校，缺键 / CSP 产物，语言检测 / 保存失败 / 旧响应 / 重载，原生 pending 恢复，三平台真实 WebView 的首帧、菜单、对话框、读屏与精确金额。系统所有文案由应用控制、繁体翻译以及原文自动翻译均不作承诺。实现前不存在这些平台结果；最终实现状态需 bun run verify 十项通过。
