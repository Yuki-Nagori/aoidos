# 记忆算法候选与标定

更新日期：2026-10-06。状态：**实验计划，算法与数值未冻结**。本附录服务于[记忆设计](memory.md)，不表示已有运行时或实验结果。[Herta 调查](../research/001-herta.md)仅提供参考，其人物陪伴场景的门槛和半衰期不直接用于 Mythos。

## 已确定的接口职责

素材资格先按提交状态、有效路径、记录种类 / 完成状态核验；摘要只能定位原始来源，场外偏好不赋予角色知识。资格检查对新增、强化和回写共同生效。

回声与重复筛选是纯函数，输入有界素材、有效来源和现有条目，输出强化原因或新增候选；不访问网络、不写文件、不修改世界。计分提交方负责按原因幂等，匹配本身不能产生重复加分。LLM 按已确认分类给出结构化候选；程序核验后提交，精确 schema 与预算尚未定型。

衰减函数输入基准强度、已确认强化、逻辑时间与策略参数，输出用于排序的值；归档选择独立于删除。复活重置时钟；失效来源不能凭高分重新进入有效候选。具体函数签名和字段在设计定稿后确定。

## 标定优先级（已确认）

1. 先减少错记：错误合并、实体串联、错误强化与越权知识优先于暂时漏记；发现歧义仍按玩家确认规则处理，不将漏记容忍解释为可静默跳过已识别歧义。
2. 再保证关键内容保留：重要承诺、关系变化与未解决线索在长对局中仍可找到，测量来源召回与最终可用内容，不能只看模型评分。
3. 防止重复刷强度：反复相同措辞不能使普通记忆永久压过其他重要经历；幂等约束与语义重复刷分分别验证。
4. 最后优化费用与延迟：质量达标后比较批次和调用频率，不单凭最低费用选方案。

衰减以指数、分段及无衰减三组对照，当前不选定胜出公式。半衰期、强化幅度、容量和质量接纳阈值凭样本与实验确定，不能用假定数值冒充实测。改写、错字、否定、新事件、回退及长对局属于必测样本，不以原句重复测试代替实际语义验证。

## 候选与排除条件

| 项目       | 候选                                                 | 对照与排除条件                                                                               |
| ---------- | ---------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| 回声匹配   | 字面片段、字符 / 词粒度重合                          | 同名 / 模糊相似不直接加分；否定 / 纠正 / 关系变化不强化旧印象；明确回指的精确识别与阈值待研  |
| 重复筛选   | 标题 / 正文相似度配合来源与主题                      | 相同措辞但事件相反不能合并；跨分支无效来源不能复用                                           |
| 衰减       | 指数 `S = B × 2^(-Δ/H)`；分段衰减；无衰减基线        | B 为有效基准强度、Δ 为选定逻辑时间差、H 为候选半衰期；均无冻结值                             |
| 强化       | 已确认收益递减、单条封顶、同经历重复受限             | 同源幂等与跨回合复述限额分别验证；新事件独立判断；增益 / 递减速度 / 封顶 / 窗口 / 次数待标定 |
| 冲突排序   | 有效且角色可见的来源；明确纠正更新认知，未决保留疑惑 | 新旧 / 强弱不判真；旧印象 / 来源保留；角色记忆回写不覆盖世界事实                             |
| cycle 归档 | 可信权重与代际距离的有界排序                         | 与会话衰减分开；同 id 去重如何保留来源 / 版本需明定；不据此删除历史                          |

公式仅为待比较的数学候选；基础时间单位已确定为完成的场内回合，没有冻结默认参数。离线时间、失败 / 取消、重放和场外聊天不计入衰减，剧情时间跳跃仅按明确剧本规则处理。采用任何候选前需验证排序稳定性、有限值、同输入确定性、时间不倒退及平局处理。不能以参考项目已有公式替代本项目的实测。

## 实体名称与语义判定验证

人物、地点、组织、物品与术语的名称 / 别名只用于寻找稳定实体 ID；按类别与范围校验。验证材料需覆盖“李雷 / 李磊”明确指向、同时存在两个候选、介绍新人物、别名占用、别名撤销、回退后来源失效和新周目隔离。补充跨地区同名地点、跨类别同名、机制不同但意思相近的术语、缩写与普通指代样本；“那座城”等本次指代不能自动成为永久别名。自动登记必须满足已确认边界；名称近似与明确指向的算法 / 阈值未冻结。

歧义交互样本需覆盖明确选择、新对象 / 都不是、跳过 / 未答复、重复检测、迟到回答、回退与周目切换。未答复时游戏沿用既有默认流程，相关记忆修改不提交；询问不重复占用模型调用，不计为场内回合。补充待办持久化重启、相同歧义合并、失效退出待办、离线仍保留有效问题、分页 / 缓存 / 总量超限提示和跨周目隔离；容量与审计期限待标定。

事件分类样本必须覆盖原句复述、不同措辞复述、同人物不同事件、补充细节、否定与纠正。增加结构化结果的来源 / 区间错误、虚构 ID、分类与字段不一致、有效不确定与调用故障区分等样本。分别观察候选召回和最终误合并 / 误强化，不能仅靠原句字符重复测试宣称语义分类可靠。逐字匹配用于忠实引用，不能代替人物识别或事件语义判断。

## 标定材料

构建经核验的样本：关键剧情、关系变化、真实玩家偏好、伏笔、闲聊、重复叙述、一次行为被误判为长期偏好、普通细节被误判为伏笔、否定 / 纠正、同名 NPC、场外输入、失败 / 取消回合、因果回退、长时间离线、跨周目刻痕。为每条保存原文和来源，人工标注应记 / 不应记、重复 / 新事件、允许摘要范围及可见对象。

玩家逐字引用、无效来源排除、重复提交幂等和正文硬上限属于必须通过的正确性约束，不能为提高召回率放宽。剧情 / 关系 / 玩家偏好 / 伏笔的允许范围已确认，见记忆设计；模型评分权重用独立样本校准，拒绝条件与来源核验不交给评分抵消。

## 角色获知权限验证

覆盖同场景但未听见、旁白独有信息、传闻、玩家元知识及场外确认；模型高置信度不能替代获知证据。验证传闻经压缩 / 强化 / 归档复活后仍保留来源与不确定性，因果回退后失效的获知依据不能继续赋予角色知识。具体证据与权限判定协议待定，本节列出验证计划，不声称已有实验结果。

## 后续注入选择验证

后续可选注入先过滤有效性 / 正文健康 / 可见权限，再按场景、实体、目标和玩家输入相关性选择，并同时限制条目数与总 token。验证旧高强度条目不能压过必要纠正限定，未决冲突不被单边摘取；必要原文查阅有界，不能挤掉 006 必需上下文。候选召回、排序权重及注入上限待实测，v1 不因此接入热路径。

## 正文长度标定

采用简短、独立可读的摘要正文，完整原文通过来源查阅。按事件长度、主体数量、否定 / 纠正、专名与多条关联采样，比较摘要长度与关键限定保留率；正文更新不无限追加细节，长事件只按语义独立信息拆分。验证不能机械分片绕过单条 / 批次 / 总量限制，字面截断不能改变认知或事实含义。具体长度、关联数量和模型输入预算仍待实测。

## 活动容量实验

用户确认以每周目总计 1,000 条活动记忆作为宽松实验配置，不作为已验证默认。按独立信息与各主体实际条目分别计数，测量门控 / 去重后增长、多主体认知扩张、优先保留条目占比和归档触发频率。覆盖 50 / 100 / 200 回合及更长对局，不能用“每回合 0.5–1 条”的规划假设代替采样结果。

归档为兜底，验证关键线索 / 承诺 / 未决关系来源有效且优先保留，平局确定，优先条目也超限时明确提示。活动容量与单次注入预算、磁盘旧版本 / 备份 / 待确认容量分别测试；不能为了证明 1,000 条可存储就将其全部注入模型。

## 调用预算标定

采用统一费用调用预算，主流程优先，不建立记忆专属额度；采用周目 / 全应用自然月双作用域金额限制，默认金额由参考 Token 用量与模型计价计算；Token 保留原始用量与单次限制，精确计价由 027 设计。语义分类与值得记合并为有界批次请求，比较其与分步判定的质量、延迟和实际用量；本地来源 / 幂等 / 衰减计算不消耗模型调用。触发方式已确认：按素材数量 / token 合批、节点切换额外时机，必要处理由引擎明确计划。单批大小、输入 / 输出上限、具体频率、usage 归一化 / 计价版本 / 周期归属、估算余量与未确认消耗核对仍待确定；预留 / 结算产品规则已确认，协议状态和字段需定型，不能只凭成功请求数量判断成本。

已知价格预算不足的测试区分必要请求暂停与可选后台跳过，验证无新素材不调用，重放 / 未回答 / 重复检测不额外调用，必要请求不机械等待合批，无隐藏续费请求和重复确认调用；恢复不收费，缺失 usage 不当零。增加已知价格预留不足不发请求、完整 usage 结算释放余量、超时 / 失败保留未知消耗、预算状态重启恢复、重复回调不重复结算及重试占预算等样本。计价变化不修改原始 Token 用量，未登记模型 / 必需价格缺失时强制补齐，校验前不发请求，不套其他模型价格或默认零价；验证输入 / 输出分开计算默认金额，金额主视图不将估算冒充账单。加入周目 / 月度供应商 + 模型分组费用与输入 / 输出 / 总 Token、请求次数汇总一致性，未知数据显示状态不填零，以及模型 A / B 切换后的逐请求计价与总额累加、旧用量不按新价格重算、默认限额不自动变化及周目 / 月度 80% 提醒去重样本。测试同请求两级预留 / 结算、新周目不重置月用量、自然月刷新留历史、改上限不清零及跨月未确认请求；预算时区初始持久保存、设置可手动选择、设备时区变化不重置，请求按发出时周目 / 月份归属，迟到回调只结算原周期；手动修改时区下一预算月生效并显示时间，当前月不变，切换不得重复刷新。统一预算不撤销 005 / 006 已有单请求预算、物理请求上限和上下文硬限。

模型登记测试覆盖首次未登记、必要价格缺项、单位 / 币种校验、明确零价与缺失区别、用户取消填写，以及填写完成后预留 / 发请求；验证必填前没有 HTTP 请求，也不记录虚假消费。不得以只记 Token 或非月额度场景绕过登记。

历史未计价测试覆盖原始 usage 保留、补价只核算适用未计价记录、原周期归属、已结算不重算、月小计 / 80% 提示不完整说明和重复补价幂等。历史未计价与新的缺价请求必填规则分开，不能因历史缺数据默许新请求继续缺价。

## 对照实验

固定相同记录、有效路径、预算与模型配置，比较无会话记忆、仅门控、门控加强化、门控加衰减 / 归档；cycle 另做独立对照，不混算会话收益。模型结果保存脱敏版本与配置身份，纯函数重放应给出相同选择。

| 评估面 | 观察项                                                                                 |
| ------ | -------------------------------------------------------------------------------------- |
| 质量   | 应记素材保留、误记、重复新增、专名丢失、冲突误覆盖、越权跨周目知识                     |
| 时间   | 短 / 长对局排序变化、复活效果；核验离线 / 失败 / 取消 / 场外回合不衰减，重放不重复计时 |
| 资源   | 输入 / 输出 token、调用次数、费用、延迟、队列峰值、正文 / 索引 / 备份大小              |
| 恢复   | 回退后候选失效、重放不收费 / 不加分、文件与索引提交故障可恢复                          |

## 回退验证计划

复用记录分支，不增加独立分支系统或自动分支合并。验证失效新增 / 强化 / 纠正撤回、别名多来源支持、旧确认回答失效，以及混合来源摘要整体停用后恢复有效版本。区分正文损坏恢复与剧情回退：前者不撤销世界进度，后者按有效路径重建派生结果；原始历史不删除，重放不收费。

## 存储故障验证计划

版本正文与事务切换指向已确认。故障注入覆盖恢复信息保存前后、正文持久化前后、SQLite 提交前后及结果不确定、发布事件失败；并覆盖文件缺失 / 哈希不符、首次新增、来源回退失效及旧版本并发变更。验证未提交版本不被读取，已提交操作不重复计分，恢复不调用 LLM，不将损坏正文视为空内容。损坏恢复已确认：隔离、核验旧版本 / 有效来源、新审计操作与明确提示；无可用版本停用，不自动补写。验证健康记忆继续使用、世界事实不回滚、过期 / 并发旧版本不能误恢复。多个旧版本选择与未引用版本清理的精确协议尚待细化。

## 复活滥用验证

严格验证同名、模糊匹配和仅检索命中不能复活；明确重提须有效来源 / 同主体 / 可见权限 / 语义核验。复活仅重置衰减时钟，不清零强化上限、重复限制和幂等记录。覆盖原来源重放、跨回合改写刷时钟、归档 / 复活循环、伪装新增条目、并发重复候选、容量满及来源回退失效，确保不能通过复活绕过已确认约束。复活冷却已确认，窗口内普通重提不重置时钟，新事件独立判断，复活不自动加分；验证冷却跨正文版本保留，离线 / 场外不消耗逻辑窗口。窗口长度与复活频率数值待标定。

## 保留与清理验证

清理前核验当前指向、保留分支、未完成操作和有效恢复版本等依赖；覆盖扫描失败、并发新增引用、恢复在进行、删除失败及清理中断重开。验证不能按文件时间删除仍有依赖的版本，不顺带删除原始记录 / 归档，唯一有效恢复版本受保护；无法安全回收时提示占用。保留数量 / 期限 / 磁盘上限及有界扫描批次尚待标定。
