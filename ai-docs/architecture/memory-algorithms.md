# 记忆算法候选与标定

更新日期：2026-10-06。状态：**推荐算法与标定方案，生产数值待实测审定**。本附录服务于[记忆设计](memory.md)，不表示已有运行时或实验结果。[Herta 调查](../research/001-herta.md)仅提供参考，其人物陪伴场景的门槛和半衰期不直接用于 Aoidos。

## 已确定的接口职责

素材资格先按提交状态、有效路径、记录种类 / 完成状态核验；摘要只能定位原始来源，场外偏好不赋予角色知识。资格检查对新增、强化和回写共同生效。

回声与重复筛选是纯函数，输入有界素材、有效来源和现有条目，输出强化原因或新增候选；不访问网络、不写文件、不修改世界。计分提交方负责按原因幂等，匹配本身不能产生重复加分。LLM 按已确认分类给出结构化候选；程序核验后提交，精确 schema 与工程预算见[记忆工程协议 v1](memory.md)和本篇参数表，尚未实现。

衰减函数输入基准强度、已确认强化、逻辑时间与策略参数，输出用于排序的值；归档选择独立于删除。复活重置时钟；失效来源不能凭高分重新进入有效候选。函数输入职责、字段与定点规则见工程协议 v1 及本篇参数计划，具体代码类型在实施时落地。

## 标定优先级（已确认）

1. 先减少错记：错误合并、实体串联、错误强化与越权知识优先于暂时漏记；发现歧义仍按玩家确认规则处理，不将漏记容忍解释为可静默跳过已识别歧义。
2. 再保证关键内容保留：重要承诺、关系变化与未解决线索在长对局中仍可找到，测量来源召回与最终可用内容，不能只看模型评分。
3. 防止重复刷强度：反复相同措辞不能使普通记忆永久压过其他重要经历；幂等约束与语义重复刷分分别验证。
4. 最后优化费用与延迟：质量达标后比较批次和调用频率，不单凭最低费用选方案。

衰减以指数、分段及无衰减三组对照，当前不选定胜出公式。半衰期、强化幅度、容量和质量接纳阈值凭样本与实验确定，不能用假定数值冒充实测。改写、错字、否定、新事件、回退及长对局属于必测样本，不以原句重复测试代替实际语义验证。

## 候选与排除条件

| 项目       | 候选                                                 | 对照与排除条件                                                                               |
| ---------- | ---------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| 回声匹配   | 字面片段、字符 / 词粒度重合                          | 同名 / 模糊相似不直接加分；否定 / 纠正 / 关系变化不强化旧印象；明确回指的精确识别与阈值待研  |
| 重复筛选   | 标题 / 正文相似度配合来源与主题                      | 相同措辞但事件相反不能合并；跨分支无效来源不能复用                                           |
| 衰减       | 指数 `S = B × 2^(-Δ/H)`；分段衰减；无衰减基线        | B 为有效基准强度、Δ 为选定逻辑时间差、H 为候选半衰期；均无冻结值                             |
| 强化       | 已确认收益递减、单条封顶、同经历重复受限             | 同源幂等与跨回合复述限额分别验证；新事件独立判断；增益 / 递减速度 / 封顶 / 窗口 / 次数待标定 |
| 冲突排序   | 有效且角色可见的来源；明确纠正更新认知，未决保留疑惑 | 新旧 / 强弱不判真；旧印象 / 来源保留；角色记忆回写不覆盖世界事实                             |
| cycle 归档 | 可信权重与代际距离的有界排序                         | 与会话衰减分开；同 id 去重如何保留来源 / 版本需明定；不据此删除历史                          |

公式仅为待比较的数学候选；基础时间单位已确定为完成的场内回合，没有冻结默认参数。离线时间、失败 / 取消、重放和场外聊天不计入衰减，剧情时间跳跃仅按明确剧本规则处理。采用任何候选前需验证排序稳定性、有限值、同输入确定性、时间不倒退及平局处理。不能以参考项目已有公式替代本项目的实测。

## 标定材料

构建经核验的样本：关键剧情、关系变化、真实玩家偏好、伏笔、闲聊、重复叙述、一次行为被误判为长期偏好、普通细节被误判为伏笔、否定 / 纠正、同名 NPC、场外输入、失败 / 取消回合、因果回退、长时间离线、跨周目刻痕。为每条保存原文和来源，人工标注应记 / 不应记、重复 / 新事件、允许摘要范围及可见对象。

玩家逐字引用、无效来源排除、重复提交幂等和正文硬上限属于必须通过的正确性约束，不能为提高召回率放宽。剧情 / 关系 / 玩家偏好 / 伏笔的允许范围已确认，见记忆设计；v1 分类 / 维度的 prompt 与接纳效果用独立样本校准，拒绝条件与来源核验不交给评分抵消。

调参集与独立验收集分开，记录样本及标注版本；同一素材的近似改写需考虑分组划分，避免用近乎相同的内容同时调参和证明效果。划分方法、比例与接纳阈值待实验计划定型，不声称已有独立验收结果。

## 正确性与运行期验证计划

以下仅列验证场景；产品规则以[记忆系统](memory.md)为准，当前未执行运行期验证。

### 实体名称与语义判定验证

人物、地点、组织、物品与术语的名称 / 别名只用于寻找稳定实体 ID；按类别与范围校验。验证材料需覆盖“李雷 / 李磊”明确指向、同时存在两个候选、介绍新人物、别名占用、别名撤销、回退后来源失效和新周目隔离。补充跨地区同名地点、跨类别同名、机制不同但意思相近的术语、缩写与普通指代样本；“那座城”等本次指代不能自动成为永久别名。自动登记必须满足已确认边界；名称近似与明确指向的算法 / 阈值未冻结。

歧义交互样本需覆盖明确选择、新对象 / 都不是、跳过 / 未答复、重复检测、迟到回答、回退与周目切换。未答复时游戏沿用既有默认流程，相关记忆修改不提交；询问不重复占用模型调用，不计为场内回合。补充待办持久化重启、相同歧义合并、失效退出待办、离线仍保留有效问题、分页 / 缓存 / 总量超限提示和跨周目隔离；容量与审计期限待标定。

事件分类样本必须覆盖原句复述、不同措辞复述、同人物不同事件、补充细节、否定与纠正。增加结构化结果的来源 / 区间错误、虚构 ID、分类与字段不一致、有效不确定与调用故障区分等样本。分别观察候选召回和最终误合并 / 误强化，不能仅靠原句字符重复测试宣称语义分类可靠。逐字匹配用于忠实引用，不能代替人物识别或事件语义判断。

### 严格结构与引用校验

覆盖引用越界、错误区间、重复文本及多字节文本定位错误；错误区间拒绝对应候选，不因其他位置逐字匹配而自动重定位。覆盖候选未知字段与不支持的顶层协议版本：前者拒绝对应候选，后者拒绝整个输出，不猜测或忽略后消费，不将格式失败交给玩家确认。原始记录区间沿用 UTF-8 字节口径；具体字段、引用映射与版本见工程协议 v1。

验证程序提供的有界片段引用 ID 能正确映射原始记录与合法字节区间，模型无需计算偏移；覆盖中文、多字节字符、重复文本、同字不同来源、未知引用、过期引用及映射损坏。逐字引文由程序提取，模型摘要不冒充引文；提取保留原标点 / 空白及场内外 mode，来源失效后不能借已有片段继续提交。

批次引用验证覆盖不同批次的同名 ID、旧响应迟到、重启恢复、映射保存失败及来源回退失效；只能按所属批次解析，不能套用当前批次映射，恢复不发新收费请求。片段验证覆盖超长记录、否定跨边界、转述 / 指代 / 纠正跨边界及多字节边界；完整行优先，必要切分有界且保留原文映射与邻接上下文，上下文计入输入预算，不能把截断部分当完整语义。

### 角色获知权限验证

覆盖同场景但未听见、旁白独有信息、传闻、玩家元知识及场外确认；模型高置信度不能替代获知证据。验证传闻经压缩 / 强化 / 归档复活后仍保留来源与不确定性，因果回退后失效的获知依据不能继续赋予角色知识。覆盖亲眼见到、直接被告知和听到传闻的来源区分，以及已获知但未相信的陈述；不能将“玩家声称国王死亡”写成已确认死亡或角色确信。具体证据与权限判定见工程协议 v1，本节列出验证计划，不声称已有实验结果。

角色推断样本包含“见到血迹 → 怀疑有人受伤”、推断错误及后续纠正。验证来源可核验，“推测”限定跨压缩 / 强化 / 归档复活保留，不变成亲历或世界事实；纠正后原推测与变化过程可追溯。

结构化验证覆盖“听说但怀疑”“亲眼看到却误解”，分别检查来源、角色主体、获知方式与认知状态。改写摘要、删除相关关键词或加入“我相信”措辞不能改变结构化权限；摘要不得替代有效来源或主体归属。

默认认知状态验证覆盖已获知但未表达态度的消息：保持“未表态”，不能当作未知或否定。高可信告知者、高记忆强度、重复告知均不能单独升级为确信；有有效态度来源时才提交对应变化，并保留过程。

认知态度首版验证覆盖未表态、相信、存疑、否定；角色相信 / 否定不等于世界事实真 / 假。“推测”“传闻”限定不因态度变化消失，模型置信百分比及记忆强度不能自动转换态度。

验证推断标记与获知方式并存，例如“由传闻推断”；先传闻、后观察时逐来源保留方式 / 范围 / 因果引用，不把旧传闻改成亲历。态度更新须来自有效记录中的角色表达或引擎明确规则，后台模型仅凭设定 / 上下文推定的未表达态度不能提交。

### 回退验证计划

复用记录分支，不增加独立分支系统或自动分支合并。验证失效新增 / 强化 / 纠正撤回、别名多来源支持、旧确认回答失效，以及混合来源摘要整体停用后恢复有效版本。区分正文损坏恢复与剧情回退：前者不撤销世界进度，后者按有效路径重建派生结果；原始历史不删除，重放不收费。

### 存储故障验证计划

版本正文与事务切换指向已确认。故障注入覆盖恢复信息保存前后、正文持久化前后、SQLite 提交前后及结果不确定、发布事件失败；并覆盖文件缺失 / 哈希不符、首次新增、来源回退失效及旧版本并发变更。验证未提交版本不被读取，已提交操作不重复计分，恢复不调用 LLM，不将损坏正文视为空内容。损坏恢复已确认：隔离、核验旧版本 / 有效来源、新审计操作与明确提示；无可用版本停用，不自动补写。验证健康记忆继续使用、世界事实不回滚、过期 / 并发旧版本不能误恢复。旧版本选择沿当前历史链查找最近健康、来源有效且不重启已被有效纠正撤回的认知版本；验证其他分支创建时间更新的版本不能因此被选中。历史链异常、扫描预算与清理协议见工程协议 v1，故障结果待实施验证。

提交验证覆盖候选生成后当前版本变化：拒绝旧候选，不覆盖并发新版本，不立即追加收费请求，需要重新判断时进入下一次已授权批次。覆盖正文未变但 stateRevision 已更新、同 entry 多候选的顺序计分、独立操作部分成功、相互依赖修改的正文准备失败、事务失败 / 结果不确定及恢复重放；独立已提交结果不被撤销，依赖操作的指向 / 来源 / 幂等标记不能只提交一半。

### 复活滥用验证

严格验证同名、模糊匹配和仅检索命中不能复活；明确重提须有效来源 / 同主体 / 可见权限 / 语义核验。复活仅重置衰减时钟，不清零强化上限、重复限制和幂等记录。覆盖正文无变化的 repeat 不覆盖态度 / 摘要、原来源重放、跨回合改写刷时钟、归档 / 复活循环、伪装新增条目、并发重复候选、容量满及来源回退失效，确保不能通过复活绕过已确认约束。复活冷却已确认，窗口内普通重提不重置时钟，新事件独立判断，复活不自动加分；验证冷却跨正文版本保留，离线 / 场外不消耗逻辑窗口。窗口长度与复活频率数值待标定。

### 保留与清理验证

清理前核验当前指向、保留分支、未完成操作和有效恢复版本等依赖；覆盖扫描失败、并发新增引用、恢复在进行、删除失败及清理中断重开。验证不能按文件时间删除仍有依赖的版本，不顺带删除原始记录 / 归档，唯一有效恢复版本受保护；无法安全回收时提示占用。保留策略以依赖保护为准，扫描工程上限见下文；磁盘占用 / 长对局效果仍待实测，不自动过期删除历史。

### 后续注入选择验证

后续可选注入先过滤有效性 / 正文健康 / 可见权限，再按场景、实体、目标和玩家输入相关性选择，并同时限制条目数与总 token。验证旧高强度条目不能压过必要纠正限定，未决冲突不被单边摘取；必要原文查阅有界，不能挤掉 006 必需上下文。候选召回、排序权重及注入上限待实测，v1 不因此接入热路径。

## 资源与参数标定

### 正文长度标定

采用简短、独立可读的摘要正文，完整原文通过来源查阅。按事件长度、主体数量、否定 / 纠正、专名与多条关联采样，比较摘要长度与关键限定保留率；正文更新不无限追加细节，长事件只按语义独立信息拆分。验证不能机械分片绕过单条 / 批次 / 总量限制，字面截断不能改变认知或事实含义。具体长度、关联数量和模型输入预算仍待实测。

### 活动容量实验

用户确认以每周目总计 1,000 条活动记忆作为宽松实验配置，不作为已验证默认。按独立信息与各主体实际条目分别计数，测量门控 / 去重后增长、多主体认知扩张、优先保留条目占比和归档触发频率。覆盖 50 / 100 / 200 回合及更长对局，不能用“每回合 0.5–1 条”的规划假设代替采样结果。

归档为兜底，验证关键线索 / 承诺 / 未决关系来源有效且优先保留，平局确定，优先条目也超限时明确提示。活动容量与单次注入预算、磁盘旧版本 / 备份 / 待确认容量分别测试；不能为了证明 1,000 条可存储就将其全部注入模型。

## 参数约束与初始实验配置

### 公式与确定性计算

令 n 为本条同经历在当前窗口内已接纳的有效强化次数，候选增量为 `floor(reinforcementGain / (1+n))`；同源已处理、n ≥ repeatLimit 或累计有效增量已达 reinforcementCap 时，不再加分。新事件按新条目处理，不借复述限额压掉；回退后按有效来源账本重建 n，撤回失效增量；已经接纳的有效 gain 按原审计值保留，不因前项撤回把后项重新算大。

`B = min(strengthCap, baseStrength + sum(validGains))`；Δ 为当前有效路径逻辑时钟减去条目创建 / 最近有效复活锚点。创建锚点取相关素材的逻辑位置而非后台实际处理时间，避免延迟处理让旧经历变成“新鲜”；没有新 completed 的玩家素材绑定当时已确认逻辑位置。强化不额外重置复活锚点，复活不清空增量 / 冷却 / 同源记录。锚点不在有效路径或时间关系非法时停止计算并恢复，不用负时间 clamp 掩盖错误。

| 候选   | 概念公式                   | 定点实现与验证                                                                                                                           |
| ------ | -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 指数   | `S = B × 2^(-Δ/H)`         | 版本化整数率表给出 `r = round(Q × 2^(-1/H))`；策略冻结 r / 表版本。factor 用定点二进制幂，乘法后向下整除 Q，最终 `floor(B × factor / Q)` |
| 分段   | `S = B × max(0, 1-Δ/(2H))` | 计算 `floor(B × max(0,2H-Δ)/(2H))`，使用受检整数运算                                                                                     |
| 无衰减 | `S = B`                    | 作为对照，仍执行容量、来源、强化 / 冷却限制                                                                                              |

率表在标定工具中生成并以版本管理，运行时不在每回合 powf 后重算排序；单个策略的可重放输入包含实际整数率。二进制幂从 factor=Q、base=r、n=Δ 开始，固定从低位向高位处理；奇数位 factor=floor(factor×base/Q)，随后 base=floor(base×base/Q)、n=floor(n/2)，每步相同截断规则，使用受检宽整数，测试 0 / 1 / 大 Δ、上限、溢出与跨平台黄金值。近似误差纳入衰减标定，不宣称离散公式等于无限精度数学值。

归档排序先过滤无效 / 损坏 / 无权内容，再按可信任务关联的保留优先级、定点分数降序、最近有效素材的逻辑位置降序、entryId 字节序升序。必需优先条目也超容量则返回 CapacityBlocked，保留新素材 / 原记录，不强删或声称全部保存成功。周期归档与会话强度不同：同刻痕 ID 合并有效来源，先按剧本声明 priority 降序，再按 cycleGen 降序和刻痕 ID 排序；不将代数直接乘权重或让模型自由填 priority。

名称近似检查的开发候选为：相同规范名称 / 已确认别名、短名称编辑距离 ≤1、长名称归一化距离 ≤0.2，以及可信音码完全相同。按类别 / 范围执行，音码目录及 Unicode 规范化版本需固定。此门只发现冲突 / 召回候选，不以相似度自动登记别名；召回不足仍可能漏冲突，需姓名 / 地名 / 术语样本评估后审定阈值。

硬上限是保护进程和协议的 v1 工程约束，发布前需资源压力测试；策略不能把它们设为无限。父级 005 / 006 / IPC 限额更小时取更小值。开发批次起点用于比较吞吐 / 延迟，未称其为最优值。

### 标定接纳与结果记录

建立人工标注样本，按原始事件分组划分调参集 / 独立验收集，近似改写不跨组泄漏。开发划分可取 70% / 30% 并标记样本版本；生产接纳比例与质量目标在正式实验前登记，不看完结果再移动门槛。硬正确性用确定性测试要求全部通过；语义错合并 / 误强化、漏记与实体召回分别报告，不用综合分抵消越权。

初轮关键模型样本每配置运行 3 次，预算不足时减少样本覆盖并报告未完成，不无限追加直到满意；纯函数重放不是随机实验。记录模型 / profile / prompt / schema / 策略 / 样本版本、输入输出 Token、物理请求数、实际 / 未确认费用、耗时、拒绝和歧义比例、每次失败结果。生产模型支持范围只限实际验证过的配置，不把一个模型的结果当所有模型保证。

上线候选必须满足：确定性权限 / 来源 / 幂等 / 字节引用 / 预算测试全部通过，独立验收集无已知越权或错误事实提交，关键保留与语义错误率有人工可复核报告；若仍有错合并案例，修正规则或收窄自动接纳范围后重新验收，不以低延迟覆盖失败。H / 增益 / 窗口 / 容量的生产值以及可接受的漏记 / 询问率只随该报告审定，当前不伪造百分比结果。
