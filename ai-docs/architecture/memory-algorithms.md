# 记忆算法候选与标定

更新日期：2026-10-06。状态：**实验计划，算法与数值未冻结**。本附录服务于[记忆设计](memory.md)，不表示已有运行时或实验结果。[Herta 调查](../research/001-herta.md)仅提供参考，其人物陪伴场景的门槛和半衰期不直接用于 Mythos。

## 已确定的接口职责

回声与重复筛选是纯函数，输入有界素材、有效来源和现有条目，输出强化原因或新增候选；不访问网络、不写文件、不修改世界。计分提交方负责按原因幂等，匹配本身不能产生重复加分。

衰减函数输入基准强度、已确认强化、逻辑时间与策略参数，输出用于排序的值；归档选择独立于删除。复活重置时钟；失效来源不能凭高分重新进入有效候选。具体函数签名和字段在设计定稿后确定。

## 候选与排除条件

| 项目       | 候选                                          | 对照与排除条件                                                      |
| ---------- | --------------------------------------------- | ------------------------------------------------------------------- |
| 回声匹配   | 字面片段、字符 / 词粒度重合                   | 短专名、同音字、套话、标点变化不能造成无界强化；阈值待研            |
| 重复筛选   | 标题 / 正文相似度配合来源与主题               | 相同措辞但事件相反不能合并；跨分支无效来源不能复用                  |
| 衰减       | 指数 `S = B × 2^(-Δ/H)`；分段衰减；无衰减基线 | B 为有效基准强度、Δ 为选定逻辑时间差、H 为候选半衰期；均无冻结值    |
| 强化       | 有上限累加；收益递减                          | 连续重复输入与重放不得无限增益；重复原因不得加分                    |
| 冲突排序   | 先来源有效性，再按已确认语义与排序策略处理    | 新旧 / 强弱不能替代事实核验；M01 未定前不自动覆盖事实               |
| cycle 归档 | 可信权重与代际距离的有界排序                  | 与会话衰减分开；同 id 去重如何保留来源 / 版本需明定；不据此删除历史 |

公式仅为待比较的数学候选，没有指定单位或默认参数。采用任何候选前需验证排序稳定性、有限值、同输入确定性、时间不倒退及平局处理。不能以参考项目已有公式替代本项目的实测。

## 标定材料

构建经核验的样本：关键剧情、关系变化、真实玩家偏好、伏笔、闲聊、重复叙述、否定 / 纠正、同名 NPC、场外输入、失败 / 取消回合、因果回退、长时间离线、跨周目刻痕。为每条保存原文和来源，人工标注应记 / 不应记、重复 / 新事件、允许摘要范围及可见对象。

玩家逐字引用、无效来源排除、重复提交幂等和正文硬上限属于必须通过的正确性约束，不能为提高召回率放宽。模型评分的“剧情 / 关系 / 偏好 / 伏笔”权重用独立样本校准，拒绝条件与来源核验不交给评分抵消。

## 对照实验

固定相同记录、有效路径、预算与模型配置，比较无会话记忆、仅门控、门控加强化、门控加衰减 / 归档；cycle 另做独立对照，不混算会话收益。模型结果保存脱敏版本与配置身份，纯函数重放应给出相同选择。

| 评估面 | 观察项                                                                    |
| ------ | ------------------------------------------------------------------------- |
| 质量   | 应记素材保留、误记、重复新增、专名丢失、冲突误覆盖、越权跨周目知识        |
| 时间   | 短 / 长对局排序变化、复活效果、离线影响、失败回合影响                     |
| 资源   | 输入 / 输出 token、调用次数、费用、延迟、队列峰值、正文 / 索引 / 备份大小 |
| 恢复   | 回退后候选失效、重放不收费 / 不加分、文件与索引提交故障可恢复             |
