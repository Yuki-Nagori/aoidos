# 002 — D&D SRD：许可边界与 Aoidos 接入

- 核验日期：2026-10-09
- 对象：Wizards 官方 SRD 5.2.1、官方创作者 FAQ 与 CC BY 4.0 许可
- 用途：为默认原创奇幻剧本筛选可复用内容，并区分许可范围、内容改编与运行时能力

## 已核验结论

SRD 5.2.1 中发布的内容可以按 CC BY 4.0 复制、翻译、改编和分发，包括商业使用；许可范围限定于该 SRD，不能据此推断所有 D&D 素材都已开放。[官方 SRD](https://www.dndbeyond.com/srd)、[创作者 FAQ](https://www.dndbeyond.com/creator-faq)。

CC BY 4.0 要求保留适当署名、来源 / 许可链接、改动说明，不能暗示原作者认可本项目，也不能额外限制受许可材料的再使用。商标等权利不由此许可一并授予。[许可概要](https://creativecommons.org/licenses/by/4.0/)、[许可正文 §2 / §3](https://creativecommons.org/licenses/by/4.0/legalcode.en)。

## 内容范围

| 内容                                                               | 本次处理                                                                                |
| ------------------------------------------------------------------ | --------------------------------------------------------------------------------------- |
| SRD 内的六属性、d20 判定、职业 / 种族 / 背景、装备、法术、怪物条目 | 可按 SRD 版本和许可复用；每项保留来源，数值规则接入前验证执行器                         |
| 火把、铃、绳索及照明 / 物体交互条目                                | 与地窖冒险有关，优先作为带来源的场景素材；没有时间 / 物品执行器时不能宣称相关数值已落实 |
| SRD 未包含的官方人物、冒险情节、设定及美术                         | 不因 SRD 获得许可，不直接搬入默认剧本                                                   |
| D&D 名称、标志、官方背书及特定品牌标识                             | 不作为 Aoidos 或剧本品牌，不暗示官方授权                                                |
| 原创地点、角色、对白和情节                                         | 自行创作，分别标记原创与第三方来源                                                      |

官方 FAQ 明确区分 SRD 与完整品牌 / 设定；例如其发布范围不含部分怪物、职业和特定命名人物。Forgotten Realms 也不在 SRD 的普通出版授权范围内，另有不同发布计划。条目必须以实际 SRD 内容核对，不凭印象扩展。[官方 FAQ](https://www.dndbeyond.com/srd#SRDv52FAQ)。

## 发布与署名

材料基准锁为 [SRD 5.2.1 官方 PDF](https://media.dndbeyond.com/compendium-images/srd/5.2/SRD_CC_v5.2.1.pdf)，不混用未登记版本。PDF 第 1 页给出其指定的英文署名声明；采用材料的剧本包随附该声明及 CC BY 4.0 许可链接，并记录中文翻译、摘录、删减与规则改编。

原创正文、第三方材料和程序代码分开标记；不把第三方 SRD 内容重新声明成独占内容。仅记录这个报告不等于已经为未来所有导入材料完成署名，打包时仍须携带对应来源记录。

## 与现有引擎的关系

**许可允许使用，不等于运行时已实现。** 当前 023 只登记 `pbta-2d6-v1`：2d6、三档结果、修正有界、同计划恰一次；D&D 的 d20 / DC、优势劣势、熟练项、职业、战斗和法术并未实现。不得把 SRD 名称贴在 PbtA 数值上后宣称完整 5E 兼容。

024 使用可信内置最小章节完成真实配置 → Provider → 持久记录 → 窗口链路。默认剧本内容真源在独立 `aoidos-scenarios` 仓库，应用只内嵌明确支持的部分。

最小原文规范与解析由 [039](../task/039-script-format-design.md) / [040](../task/040-script-parser-impl.md) 承接；完整导入另行规划。需要支持 SRD 数值规则时另行规划规则执行任务，不让解析 crate 执行骰判、SQL 或世界变更；engine 单向消费解析结果，再经可信登记核验。

## 验证限制

剧本仓库的 Python 测试器验证离线规则镜像及抽样路径，不调用真实 LLM；随机样本通过不能证明所有玩家自然语言路径、实际模型质量或版权绝对无风险。来源与许可核验、玩法测试和引擎联调各自保留实际证据。
