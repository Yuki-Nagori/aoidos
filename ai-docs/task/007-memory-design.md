1. 门控管线：回声强化（阈值 / 时间窗）、已记过（新颖性规则、复述转强化）、值得记（评分维度与 prompt 骨架、默认拒绝）、忠实门（逐字引用判定——捏造用户台词结构性拦死）。

5. 触发策略：默认关闭、门槛参数（闲置 / 冷却 / 素材量）、用户返回让位。
6. 三域边界：会话记忆、cycle、segment；回写真相权限、前缀冻结与周目 / session 身份、跨周目可见对象、节点计量与安全阀。
