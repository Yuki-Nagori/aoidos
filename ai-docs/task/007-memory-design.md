## 已确认决策摘要

| 主题       | 当前确认口径                                                                                                                      |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------- |
| 事实与认知 | 世界事实仅引擎按规则提交；角色记忆可遗忘、强化、压缩、误解，原始记录保留                                                          |
| 获知与态度 | 引擎维护有来源的获知记录；观察 / 告知 / 传闻、推断标记和认知态度分别保存；未表态 / 相信 / 存疑 / 否定不裁定世界事实               |
| 态度变化   | 依据有效记录中的角色表达或引擎明确规则，模型只提候选；强度 / 重复次数 / 模型置信度不自动升级认知                                  |
| 来源与引文 | 程序提供有界片段和批次引用 ID，持久保存映射；模型选引用并生成摘要，程序提取原文；错误引用 / 未知字段严格拒绝                      |
| 门控与实体 | 有效已提交来源先行；语义分类合批，字符相似不等于同事件；稳定实体 ID、明确指向后的别名学习及歧义询问适用于人名 / 地名 / 术语等     |
| 待确认     | 未答复沿默认流程继续，相关修改不提交；问题持久化 / 去重 / 分页，迟到回答重新核验，跨周目不继承                                    |
| 生命周期   | 已完成场内回合计时；递减强化、单条封顶、同源幂等与重复限制；严格复活冷却，归档不删除原始历史                                      |
| 容量与正文 | 每周目合计 1,000 条活动记忆作为实验配置，非生产默认或注入量；简短独立摘要、原始来源可查、有意义拆分                               |
| 存储与恢复 | 版本正文 + SQLite manifest；先持久准备、后事务切换指向；独立修改分别提交、依赖修改同一操作提交；损坏沿当前历史链恢复最近有效版本  |
| 回退与过期 | 复用 006 / 012 因果分支；撤回失效来源效果，混合摘要先停用；过期候选拒绝，需要时进入下一次授权批次，恢复不重发收费请求             |
| 高级设置   | 首版开放底层调参；应用默认 / 剧本字段覆盖；显式保存整组校验；新周目冻结完整策略，恢复默认清除剧本覆盖，已有周目不变               |
| 触发与预算 | 收集合格素材有界合批，后台默认关闭、主流程优先、单在飞；共用每局 CNY / USD 原币上限，必要请求对应币种额度不足时暂停、可选后台跳过 |
| 轮回与节点 | 剧本显式授权模糊刻痕及可见对象，不继承世界状态；段切同 session、静态前缀不变；按条件推进，停滞使用可信提示 / 出口                 |
| 标定方法   | 正确性优先，指数 / 分段 / 无衰减对照；调参集与独立验收集分开，预算内有限重复模型判定并记录失败与波动                              |

这些决策是设计约束，不表示相关 API、设置或运行时已经实现。
