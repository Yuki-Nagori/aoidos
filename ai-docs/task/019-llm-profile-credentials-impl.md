## 目标与背景

回合需要可冻结的配置和凭据副本；明文密钥不得进入 Webview。交付可保存的 profile、Rust 原生凭据输入与状态查询，以及互斥的代理模式。

## 范围与非目标

- profile 校验、持久化与冻结；回合重试使用不可变配置和凭据副本。
- 三平台 Rust 原生密码输入、OS 凭据库和私有文件降级；设置、取消、清除、权限与 hint。
- system / none / manual 代理，正常 TLS 校验、禁止重定向与脱敏诊断。
- Rust 命令及同型 TS API；复用存储基建，验证并发与恢复边界。

非目标：生成回合、Webview 明文密钥表单、供应商自动探测和完整设置界面。回合协调由 020、界面由后续产品任务承接。

## 设计决策

| 事项             | 采用方式                                                                                                                 | 规则归属                                                      |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------- |
| 逻辑读改写并发   | 命令层 profile / key 两把锁；凭据状态读取同样串行；等待原生输入不持业务锁                                                | [存储并发](../architecture/storage.md#原子写工具全仓唯一实现) |
| 两后端先后与删除 | credentials.json v2 保存 OS 指针、文件值或删除墓碑；读取按权威后端，旧字典保留文件值；跨 OS / 文件失败可能表示提交不确定 | [密钥隔离](../architecture/ipc-contract.md#工程纪律可检查版)  |
| 原生能力与线程   | Windows CredUI、macOS AppKit、Linux GTK 各自实现同型接口；命令经 UI 主线程调度，独立门禁覆盖窗口生命周期                 | [平台封装](../standards/rust.md#平台能力封装)                 |
| Sampling 归属    | 独立 `sampling.rs` 供配置、传输和阶梯共用，持久化不反向依赖传输实现                                                      | [LLM 结构](../architecture/llm.md)                            |
| 共用文件规则     | 私有发布、有界读取与祖先路径检查归 store；业务 JSON / 版本及标识符校验归 LLM                                             | [目录归属](../architecture/repository-layout.md#归属规则)     |

以上事项已处置；没有以 TODO 留下阻塞验收的实现缺口。

## 实施结果

1. `mythos-llm` 提供 `config` / `credentials` / `proxy` / `platform`；配置冻结不重新读取热更新密钥。
2. `src-tauri/src/llm_commands.rs` 提供 profile 与凭据命令；`src-web/api/llm.ts` 同型声明及薄调用。
3. 应用 setup 获取实例锁并持有到退出；私有文件先收紧空临时文件权限，再写入和发布。
4. 原生集成放 `tests/rust/native-platform` 测试 crate，显式桌面会话且 `harness = false`；CI 三平台另跑该测试。
5. 逐文件覆盖规则及平台豁免有明确台账；独立评审优化未增加豁免或提高预算。

## 风险与回退

- 无桌面会话或权威 OS 凭据不可读时显式报错，不转为 Webview 明文输入或伪装未设置；OS 写失败的私有降级按契约处理。
- OS 操作与文件发布不是分布式原子事务；失败后主动查询状态，不能假定未提交。
- 回退实现时同步撤销接口、依赖与文档；不删除已有配置或凭据。
