## 范围与非目标

- 舞台逻辑坐标与覆盖层、面板四态、动效降级、焦点 / 滚轮 / 键盘和辅助技术。
- 正式记录与公开预览、正文分段、有效路径变化、有界缓存与滚动锚、未读和错误状态。
- 输入模式预览、slash 入口、IME / 草稿版本保护、手动骰判与偏好展示、暂停 / 恢复 / 回退确认。
- 集成 026 的主题切换与当前皮肤开关；只编排完整设置视图，不复制运行时校验 / 偏好存储。
- 消费 022 的面板 / 骰判偏好存储；复用 026 的受控 main 构建入口装配窗口状态插件，恢复到可见显示器。
- 替换 024 最小联调界面，清理临时 UI 接线，补充三平台验收证据，记录最低系统 / WebView 或 webkit2gtk 版本及现代 CSS 降级。

非目标：立绘 / 地图内容、主题皮肤制作 / 校验、记忆系统、原始 reasoning 展示、Markdown、虚拟列表库或自动付费调用。021 管理正文恢复，022 管理记录与偏好存储，023 管理输入解析和骰判；本任务不实现业务副本。

1. 核验依赖和真实接口，拆分舞台、面板、记录与 composer 组件；布局和 token 消费沿用 004。
2. 在 utils 实现面板状态转换、输入预览、段落 / 未读 / 锚计算并配黄金例；composable 管理定时器、订阅、请求代次和卸载清理。
3. 接入 021 正文及 022 有界记录消费者；旧 session / viewEpoch / turn 响应不得覆盖当前视图。将 phase、公开 turn 与手动骰判按钮对齐 023。
4. 接入偏好、窗口状态及确认流程；设置失败保留上次确认值，重启不恢复焦点或敏感草稿，不自动续费。
5. 完成 Webview、IME、键盘与辅助技术、滚动性能和三平台 / DPI 验收，更新架构现状与使用说明。

## 验收标准

- [ ] 面板四态不改变舞台矩形，窄窗 / 高缩放无横向溢出；触发区不抢原生边框。
- [ ] 悬停时序、反向动画、焦点 / IME / 选区保护、钉住和 reduced-motion 符合设计；隐藏内容不可聚焦。
- [ ] 全部记录类型、预览封口、兼容只读及中断正确呈现；旧响应不覆盖，有界缓存、滚动锚和未读可验证。
- [ ] Enter / Shift+Enter / IME、slash、草稿版本与 busy 失败路径有证据；手动骰判防连击，骰值仅由 Rust 产生。
- [ ] 主动恢复、最后事件全丢失的限制与 finishReason 准确展示；关闭面板不停止业务，不暗加持续轮询。
- [ ] 偏好写入串行化、完整替换不丢另一字段、旧响应不覆盖新意图，失败保留确认值；窗口恢复到可见工作区，退出不保存敏感草稿，卸载释放全部监听 / 定时器。
- [ ] Windows / macOS / Linux 的 DPI、原生边框、键盘 / 辅助技术、滚动性能均记录；未验证平台不标通过。
- [ ] 代码、注释、类型、文档与 task 同步；最终状态 `bun run verify` 全项通过。
