## 目标与背景

实现可信获知证据、来源片段、严格候选协议、实体 / 别名 / 待确认以及独立授权处理批次。本任务承接 [007](007-memory-design.md) 的阶段 B；设计定稿不表示运行时已实现，依赖未满足前不提前开工。

## 实施步骤

- [x] 实现有界片段与批次引用；原始 UTF-8 映射持久保存，引文由程序提取。
- [ ] 通过可信引擎目录和规则证据关联角色 / 实体，未知或不完整目录不自动登记。
- [x] 落地严格候选类型与白名单校验：未知字段 / 引用拒绝，repeat 不覆盖认知正文与态度。
- [x] 实现批次身份与本地回执状态机：dispatched 前持久登记物理请求身份，received / completed 同事务保存有界结果；unknown / rejected 禁止同批次重发。
- [x] 实现待确认问题持久化：稳定事件身份、严格类型候选、候选变化递增 revision、来源复核、历史 / 目录版本 CAS、迟到回答拒绝及每周目 512 项上限；可选提及名称须能从原始来源逐字复现，选答案本身不登记别名。
- [ ] 接入可信目录与明确指向证据，完成别名登记 / 撤销 / 回退重建；未接入前不登记别名或授予角色知识。
- [x] 补齐待确认失效 / 恢复协调与面向 UI 的有界分页；过期来源 / 可信版本转 invalidated，分页最多返回 32 项、单次扫描 256 项，序号游标固定分页快照上界。
- [x] 实现纯定点强度计算：输入冻结策略、有效强化和逻辑锚点，覆盖指数、分段及无衰减策略；不负责核验来源、选择归档或写入效果。
- [x] 实现纯归档选择：必需优先，其余按强度、最近有效素材逻辑位置和 ID 字节序稳定排序；仅消费调用方已过滤的有效候选，必需条目超容量时拒绝。
- [x] 实现纯依赖组规划：共享素材或目标的候选合为原子组，按原始素材位置及 candidateId 稳定排序，每组最多触及 16 个条目。
- [x] 将候选与操作计划 / 恢复建立持久关联；批次候选绑定唯一操作，完成摘要声明 `applied` 前必须核验对应操作及提交回执，prepared / ready 操作保持批次未完成并可恢复。
- [ ] 复用 020 private / lease 与 027 的计费实施端口，回合释放后处理，不增加 012 第四次调用；实机授权门仍关闭。
- [ ] 实现别名幂等 / 撤销与来源回退重建；该能力依赖可信目录和明确指向证明。
- [x] 持久保存 localDeferred 原因，并允许已完成批次仅从原始响应 / 冻结输入本地重新核验；原回执不变，不重新发送或定时重试。

## 预计改动

业务逻辑位于 `src-rust/aoidos-memory`，依赖 `aoidos-store` 的共享 SQLite / 原子存储边界；引擎在统一迁移列表追加批次回执、问题队列、候选—操作关联和旧回执兼容迁移。升级前完成的结果仅标记为历史数据并保持可读，不推造操作映射；新批次按严格关联规则校验。Tauri 命令与前端接口仍由后续接入任务承接，本任务不提前扩张 UI / IPC。
