## 前置条件与待决策

034 已完成并通过三平台 CI，是本任务的国际化直接前置；本任务已开始实施。工程预算与算法开发值按 007 / 算法文档执行；生产默认只能由独立实验报告审定。参数按算法分别生效：指数算法使用冻结整数 `decayRate`，分段算法使用 `halfLifeRounds`，无衰减不使用二者；不从半衰期派生指数率，也不要求两者建立数值对应。该边界已在设置 UI 标注，并需保持算法文档同步。实现中发现设计冲突先同步文档，不静默扩大权限。

## 实施步骤

1. 实现类型化参数、整组 / 跨字段校验及应用 / 剧本双配置 revision CAS。
2. 实现按字段继承、显式保存、恢复默认草稿和保存失败保留确认值。
3. 新周目原子读取最终合法配置并冻结策略 / 参数 / 整数率；已有周目不静默重算。
4. 在通信契约登记记忆专属命令 / DTO（周目策略、批次状态恢复、记忆及待确认查询 / 回答）；Rust 定型后 TS 同型声明，invoke 透传。批次执行沿用 030 私有授权入口，产品侧触发器须满足费用授权和游戏 lease 约束。
5. 接入 025 设置容器与 034 国际化能力，展示生效范围、来源、待确认与脱敏恢复状态。
6. 实现有界分页、GetBatchStatus 主动恢复、跨 run 旧响应丢弃，无持续轮询；不重复实现 030 的私有批次执行器。

## 预计改动

领域与查询规则留在 `aoidos-memory` / `aoidos-engine`，Tauri 只负责命令装配和 wire DTO，前端 API 透传并由设置、查询组件承载交互；配置与查询复用已注册存储，不新增存储原语。
