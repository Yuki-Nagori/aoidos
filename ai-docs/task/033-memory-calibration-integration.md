2. 验证整数率表 / 定点幂 / 分段 / 无衰减、原有效 gain 保持、防重复 / 冷却和归档平局。
3. 明确实验预算与停止条件；关键模型样本有限重复，失败 / Token / 物理请求 / 未确认费用均记录。
4. 对照无记忆、仅门控、强化、衰减 / 归档；cycle 独立评估，覆盖错误合并 / 越权 / 关键保留。
5. 覆盖源码与 SQLite 故障、响应丢失 / 主动恢复、1,000 条活动实验容量及更长对局资源峰值。
