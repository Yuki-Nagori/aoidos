## 目标与背景

验证记忆算法的语义质量、定点策略、防刷行为、长对局资源和真实费用，并据独立证据审定生产参数与支持范围。设计定稿和功能接通不等于算法与产品已经通过验收；开发初值、合成样本和模型自评分数不能代替人工标注及独立验证。

## 范围与非目标

范围包括 033 的显式记忆处理产品链路、语义与算法标定、容量和故障实验、生产参数审定，以及相关 UI / IPC 接入。记忆请求复用 030 批次执行器、032 刻痕上下文、031 设置与查询、020 lease 和 035 费用授权；不新增回合中的模型调用、不自动发送或后台轮询，也不另建费用或检索热路径。

真实费用实验须经过应用现有记忆发送路径与 035 原币账本。玩家触发后，系统自动收集当前周目、当前因果分支内有效且未处理的素材；收集和冻结不调用模型，只有玩家明确发送才产生请求。待模型明确拒绝的素材可在新的显式授权批次重试；`unknown` 等其他非终态批次继续占用素材。

生产参数必须由留出集和独立验收报告审定。若实现或实测暴露设计冲突，先同步协议文档并记录决定，不以调整阈值掩盖失败。

### 已交付的实现与探索

- [x] 显式批次、可信 Proposal 上下文、候选操作、强化 / 复活策略与恢复路径已接入；权限、来源、幂等和 007 规则一致，并由 Rust / IPC / UI 行为测试覆盖。

- [x] Rust / TypeScript IPC 类型同型；不支持版本、上下文变化、权限拒绝和持久化失败有直接验证。
- [x] 校准集机器校验器已建立：检查至少 60 个样本组、70 / 30 组级划分、两组覆盖风险类别、ID / 来源归属、人工维护的关联组不跨集合、正例的来源 / 可见主体 / 摘要边界及跨集合完全重复原文。校验器不推断语义近似，不生成或批准人工标注。
- [x] 每次请求前在当前周目索引中定位主体的活动 / 归档目标，仅冻结固定策略命中的目标；扫描最多 10,000 条、当前版本文件合计最多 4 MiB。8–16 条是设计目标而非截断值；允许超过 64 条，硬上限为 128，完整 Provider 输入不超过 64 KiB。超预算或命中超过 128 项时失败关闭，不截断继续。冻结并校验检索策略版本、扫描 / 命中数和目标版本；字面词项 / 字符片段不保证语义召回完整，空命中不代表记忆全新，模型不确定时使用 `uncertain`。

### 资源探索样本

以下均为单次 macOS 合成实验，用于检查链路和记录格式，不构成稳定性能基准或生产结论。

- **50 / 100 / 200 回合**：回合 / 素材扫描 / 含扫描总耗时为 5.11 / 0.17 / 5.28 秒、13.47 / 1.70 / 15.17 秒、36.92 / 7.67 / 44.59 秒；记录正文为 135,815 / 265,824 / 526,910 B，含 SQLite、WAL、备份和正文的总量为 6,680,907 / 7,064,844 / 7,850,338 B。该轨迹没有提交记忆批次，不能反映活动记忆增长或队列峰值。
- **1,000 条 Active 与 200 回合**：创建 28,692 ms，检索素材收集 / 准备 / 冻结 585 ms，产品重开校验 162 ms，200 回合 50,186 ms。记录正文 673,645 B、SQLite 7,434,240 B、活动 WAL 4,124,152 B、记忆正文 999,410 B、备份 1,646,592 B，目录合计 14,910,915 B；合成 Provider 启动 400 次。Active 由夹具预载，不等于玩家实际输入；RSS 未采到。
- **10,000 条 Active 上限**：预载 112,943 ms，重开校验 517 ms，拒绝预算前后完成 12 回合共 666 ms。重开后 SQLite 28,102,656 B、WAL 1,565,632 B、记录正文 37,566 B、记忆正文 10,140,000 B、备份 1,646,592 B，目录合计 41,525,322 B；RSS 未采到。目标检索先触及 4 MiB 正文预算，不是 10,000 条成功检索。
- **Storage / SQLite 1,000 条目标检索**：独立合成素材实验扫描 1,000 条并唯一命中末位目标，冻结快照干净重开后逐字段一致；10,000 条扫描上限与 4 MiB 正文边界有定向验证。一次历史采样：创建 30,284 ms、查询冻结 224 ms、重开 139 ms；活动期间 SQLite / WAL 为 7,098,368 / 4,206,552 B，重开后 SQLite / WAL 为 7,196,672 / 0 B，记忆正文 / 记录正文 / 迁移备份为 999,178 / 150,947 / 1,646,592 B，文件总量分别为 14,134,405 / 10,026,157 B。此实验没有推进游戏回合或调用 Provider，与上面的产品链路样本分开统计。
- **进程恢复与长记录探索**：独立子进程分别在单素材批次 queued、dispatched、received 状态后退出，再由父进程重开 SQLite；received 可恢复完成且重复恢复幂等。长记录轨迹单独写入合成记录对并干净重开，没有推进游戏回合，也不是进程终止负载。macOS 曾用 `/usr/bin/time -l` 包裹三项串行集成测试，耗时 43.08 秒、主进程峰值常驻集 22,528,000 B（约 21.5 MiB），不含恢复子进程；此值与现行每项独立进程的 RSS 字段不可直接比较。上述实验均不覆盖硬件断电、文件损坏、写入失败或真实请求发送结果。

## 风险与回退
