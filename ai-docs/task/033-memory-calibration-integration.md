## 目标与背景

验证语义效果、定点算法、防刷、长对局资源与真实费用，审定可发布的参数和模型支持范围。本任务承接 [007](007-memory-design.md) 的阶段 E；设计定稿不表示运行时已实现，依赖未满足前不提前开工。

## 必读

## 范围与非目标

范围：下述实施步骤和验证，包括显式授权记忆处理的产品联调；必要的用户入口 / IPC 与提示展示也由本任务接入，并复用 031 已有设置和查询契约。非目标：不以开发初值或模型评分冒充实测；不新增隐藏实验调用、另一份计价或检索热路径；不自动排队或增加回合中的 LLM 调用次数。

## 前置条件与待决策

035 是费用实施与统计能力直接前置；当前 `implemented` 状态可供本地接口联调，但收费实验必须等待 035 完成三平台实机验收，并在每轮开始前明确预算与用户授权，不因本任务规划直接发送请求。工程预算与算法开发值按 007 / 算法文档执行；生产默认只能由独立实验报告审定。实现中发现设计冲突先同步文档，不静默扩大权限。

## 实施步骤

1. 建立人工标注、按事件分组的调参 / 独立验收集，记录样本版本，避免近似改写泄漏。
2. 验证整数率表 / 定点幂 / 分段 / 无衰减、原有效 gain 保持、防重复 / 冷却和归档平局。
3. 明确实验预算与停止条件；关键模型样本有限重复，失败 / Token / 物理请求 / 未确认费用均记录。
4. 对照无记忆、仅门控、强化、衰减 / 归档；cycle 独立评估，覆盖错误合并 / 越权 / 关键保留。
5. 覆盖源码与 SQLite 故障、响应丢失 / 主动恢复、10,000 条活动容量及更长对局资源峰值。
6. 根据独立验收报告审定生产默认及高级设置合法范围，公布支持模型范围与尚未覆盖项。
7. 将显式授权的记忆请求接到产品流程：提供用户可控入口和必要 IPC，同一 Proposal v1 请求复用 030 批次执行器与 032 刻痕上下文 / 原子完成接口，不增加模型请求或后台自动触发；提示展示前以最新 applied 世界计算 023 匹配结果，再调用 032 原子领取接口。设置、查询契约复用 031，不复制已有协议；所有发送仍受 020 lease 与 035 费用授权约束。

显式处理的素材范围已确认：玩家发起处理后，自动汇集当前周目、当前因果分支中仍有效且未处理的素材；收集和冻结不发请求，只有玩家明确发送才调用模型。待拒绝以外的批次占用素材，`unknown` 不释放占用；被模型明确拒绝的素材可由新授权批次重试。长记录切分必须稳定并持久复用，不能通过重新切分绕过来源去重。

## 预计改动

扩展现有 `src-rust/aoidos-memory` / `aoidos-engine`，存储继续复用 aoidos-store；产品触发所需的命令 / DTO 在 `src-tauri` 薄装配，前端 API 与界面按职责接入。实验数据集和本任务确有需要的产品入口可以新增；记忆仓储与领域 crate 已存在，不再作为待创建路径描述。实现 commit 同步架构、契约与 task。
