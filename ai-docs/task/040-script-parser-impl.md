## 目标与范围

创建 aoidos-script crate，最小原文读取 / 结构校验只依赖标准库，不依赖 engine / llm / tauri；引擎单向消费并映射为可信目录，存储 / 解包由受控导入边界承担。覆盖容量、编码、身份、标题、控制字符、结构标记与原文保留；不在解析器执行骰判、SQL、网络或世界变更。

## 验证计划与结果

原文字节保留、非法输入与 64 KiB / 256 字节标题 / 64 字节身份边界单测通过；默认资源与发布原文字节一致，可信映射和正式 Provider 联调通过。独立 review 无阻塞项；完整 verify 及原生验证由 024 的同次最终验证记录承载。

## 风险与回退

不可信输入不能通过解析获得可信世界写入权；不支持的原文结构 / 执行能力明确拒绝，不静默补默认规则。回退同步撤销接口与文档，保留已有记录。
