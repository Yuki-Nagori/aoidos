## 目标与范围

创建 `aoidos-script` crate，交付最小原文解析 / 结构校验及单元测试，只依赖标准库，不依赖 engine / llm / tauri。覆盖容量、编码、身份、标题、控制字符、结构标记与原文保留；不在解析器执行骰判、SQL、网络或世界变更。

可信资源登记、引擎映射和正式 Provider 联调由 [024](024-llm-engine-integration.md) 实施并独立验收；完整导入包的存储 / 解包不在本任务范围内。
